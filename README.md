# Heart Disease Prediction System

End-to-end heart disease prediction project using:

- Logistic Regression
- FastAPI
- HTML
- CSS
- JavaScript

## Model
The model uses a Logistic Regression pipeline with StandardScaler.

## Backend
FastAPI provides the `/predict` endpoint.

## Frontend
The user interface is built with HTML, CSS and JavaScript.

## Disclaimer
This project is for educational purposes only and is not a medical diagnostic tool.
