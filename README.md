# Heart Disease Prediction System

End-to-end heart disease prediction web app using:

- Logistic Regression
- FastAPI
- HTML
- CSS
- JavaScript
- Vercel

## Vercel-ready structure

- `index.html`
- `style.css`
- `script.js`
- `requirements.txt`
- `vercel.json`
- `api/index.py`
- `api/heart_disease_model.pkl`

The frontend calls `/api/predict` on the same Vercel domain.

## Disclaimer

Educational use only. This tool is not a medical diagnosis.
